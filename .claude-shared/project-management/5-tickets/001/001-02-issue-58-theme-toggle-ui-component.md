**Problem Statement:**
Users need an accessible and intuitive way to toggle between light and dark themes from anywhere in the application. The toggle must be accessible, mobile-friendly, and provide clear visual feedback about the current theme state.

**Success Criteria:**
1. Create interactive theme toggle button component using ShadCN UI
2. Add toggle to navigation/header for global accessibility
3. Implement visual indicator for current theme (sun/moon icons)
4. Add smooth animation transitions between theme states
5. Ensure full keyboard accessibility

**Technical Considerations:**
- Use ShadCN UI Button component for consistency
- Accessible button with proper ARIA labels and roles
- Icon support using lucide-react (sun/moon icons)
- Mobile-responsive design (touch-friendly sizing)
- Smooth CSS transitions for icon changes
- Keyboard navigation support (Enter/Space to toggle)

**Acceptance Criteria:**
- [ ] Theme toggle button component created (`components/theme/theme-toggle.tsx`)
- [ ] Toggle added to main navigation/header
- [ ] Current theme visually indicated with appropriate icon
- [ ] Smooth transitions between theme icons
- [ ] Accessible keyboard navigation (ARIA compliant)
- [ ] Works on mobile devices (min 44x44px touch target)
- [ ] Component properly typed with TypeScript
